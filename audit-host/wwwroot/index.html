Skorlar nasıl okunur?

Üst çubuk: özet skorla aynı eksende (düşük skor = dar çubuk); "tarama %X bitti" değildir.
Özet skoru (%): bulgu cezası; UI otomasyon oranı %50 altındaysa ek olarak en fazla %55 ile sınırlanır (sinyal susturulmaz).
UI otomasyon (%): aday öğelerden kaçının başarıyla denendiği. Partial çoğunlukla bu oranın %50 altında olması veya başarısız denemelerdir.
