# KVKK — Veri Minimizasyonu (Kısa Kontrol Listesi)

Bu liste **hukuki tavsiye değildir**. Ürünün işletiminde veri minimizasyonu için pratik kontrol noktalarını içerir.

## Kontroller

- [ ] Sistem envanterine eklendi (amaç, kapsam, sahiplik)
- [ ] Saklama süresi tanımlandı ve otomatik silme açık
- [ ] Log/trace içinde PII riski değerlendirildi, redaction/policy uygulandı
- [ ] Erişim kısıtları (API key/OIDC, network policy) devrede
- [ ] Üçüncü taraf/alt işlemci listesi güncel (varsa)

---

# KVKK — Data Minimization (Quick Checklist)

This checklist is **not legal advice**. It captures practical controls for data minimization when operating the product.

## Controls

- [ ] Added to system inventory (purpose, scope, ownership)
- [ ] Retention is defined and automated deletion is enabled
- [ ] PII risk assessed for logs/traces, redaction/policy applied
- [ ] Access controls (API key/OIDC, network policy) enforced
- [ ] Third parties/sub-processors list is up to date (if applicable)
